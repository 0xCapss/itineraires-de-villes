# Itinéraires de villes

Application de préparation d'itinéraires : 13 villes préparées (New York, Montréal, Paris, San Francisco, Vancouver, Memphis, Los Angeles, Las Vegas, Chicago, Miami, Washington, Boston, Seattle) et, via « Autre destination… », la carte de n'importe quelle ville de plus de 20 000 habitants, construite dans le navigateur à partir d'Overture Maps.

Site : https://0xcapss.github.io/itineraires-de-villes/

Données : © OpenStreetMap contributors, © Overture Maps Foundation, GTFS des exploitants de transports (voir les notes de chaque ville), photos de Wikimedia Commons (auteur et licence affichés avec chaque photo).
